# invitation-poster

A responsive, self-contained HTML recreation of the Hungarian 45th anniversary charity ball invitation poster, with consistent spacing and typography.

## Preview

To publish a preview, open the repository's **Settings → Pages** and set **Build and deployment → Source** to **GitHub Actions**. The workflow deploys the site to GitHub Pages when changes are pushed to `main`, or when run manually from the Actions tab.

To preview a branch locally, open `index.html` in a browser.
